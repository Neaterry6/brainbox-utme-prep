# Brainbox UTME Prep

A responsive UTME mock-exam prototype with student dashboard, subject practice, timed quizzes, score breakdowns, answer review, leaderboard, and admin question authoring.

## Run locally

Open `index.html` in a modern browser. The prototype stores exams and attempts in browser `localStorage`.

## Prototype notes

The current build is front-end only. Admin access is a UI demonstration, not an authenticated role. For a real multi-user deployment, connect a backend such as Supabase or Firebase for authentication, exam/question storage, attempt records, and leaderboard aggregation. Seeded sample leaderboard entries are illustrative.
